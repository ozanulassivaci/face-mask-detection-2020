# Face Mask Detection

Real-time face mask detection with OpenCV and a MobileNetV2 classifier trained
on top of Keras/TensorFlow. A lightweight face detector locates faces in a
webcam stream, and each detected face is classified as wearing a mask or not.

> 📝 TODO: add the course/resource that inspired this project

## Features

- Trains a mask/no-mask classifier by fine-tuning MobileNetV2 (ImageNet
  weights, frozen base, new classification head)
- Face detection via OpenCV's DNN module using a pretrained Caffe SSD model
  (`res10_300x300_ssd_iter_140000`)
- Real-time inference on a webcam feed with bounding boxes and confidence
  scores drawn on each frame
- Data augmentation during training (rotation, zoom, shift, shear, flip)

## Tech stack

- Python
- TensorFlow / Keras (MobileNetV2)
- OpenCV (`cv2.dnn`)
- scikit-learn (train/test split, classification report)
- imutils, NumPy, Matplotlib

## Installation

```bash
git clone <this-repo-url>
cd face-mask-detection-2020
pip install -r requirements.txt
```

This project was originally written against the library versions pinned in
`requirements.txt` (TensorFlow 1.x/early 2.x era, ~2020). Newer TensorFlow
and OpenCV versions may require minor adjustments.

## Usage

### 1. Get the pretrained face detector weights

The Caffe face detector weights (`res10_300x300_ssd_iter_140000.caffemodel`)
are not included in this repository (see [Limitations](#limitations)). This
is OpenCV's standard pretrained SSD face detector, used in many OpenCV DNN
face-detection tutorials — search for the filename together with "opencv dnn
face detector" to find it, or check the official OpenCV repositories. Place
the downloaded file in `face_detector/` next to `deploy.prototxt`.

### 2. Train the mask classifier

```bash
python src/train_mask_detector.py
```

A small representative sample of the training images is included under
`sample_dataset/` just to illustrate the expected folder layout
(`with_mask/` / `without_mask/`). To actually train the model, point
`DIRECTORY` in `src/train_mask_detector.py` at your own full dataset
following the same `with_mask/` / `without_mask/` structure, or place it at
`dataset/` in the project root (already gitignored).

This produces `models/mask_detector.model` and a training curve at
`docs/training_plot.png`.

### 3. Run real-time detection

```bash
python src/detect_mask_video.py
```

Opens your default webcam, draws a bounding box and label ("Mask" / "No
Mask") with a confidence percentage over each detected face. Press `q` to
quit.

## Limitations

- The full training dataset is not included in this repository. It was
  assembled from public face-image sources rather than photos taken by me,
  and includes real, identifiable people, so it is not something I can
  redistribute here. Only a small illustrative sample is included under
  `sample_dataset/` to show the expected folder structure.
- The pretrained face detector weights (`.caffemodel`) and the trained mask
  classifier (`models/mask_detector.model`) are not committed to keep the
  repository small; both can be regenerated or downloaded as described above.
- Tested against the older library versions pinned in `requirements.txt`;
  compatibility with current TensorFlow/OpenCV releases is not guaranteed.
- No automated tests.

This project was a simple self-study exercise I built in high school (2020)
to develop my computer/programming skills through courses I was taking at
the time. It was reorganized and cleaned up in 2026 for public release.
